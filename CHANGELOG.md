# Versions

Every version stays available, because an older copy of the app asks for its
own version. Budget Lock accepts only the version it was built for and checks
the file before using it.

| Version | Size | Released | Works with |
|---|---|---|---|
| **6.1** (current) | 478 MB | 21 Sep 2026 | Budget Lock 1.8 or newer on Android, and Budget Lock for Windows |
| 6 | 478 MB | 15 Sep 2026 | Budget Lock 1.7.2 on Android, and Budget Lock for Windows before 1.8 |

## Version 6.1 — 21 September 2026
